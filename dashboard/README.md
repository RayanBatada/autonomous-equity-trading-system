# SMA Dashboard

Run with `uv run streamlit run dashboard/app.py` from the repo root (requires `uv sync --extra dev` first). The dashboard is read-only against `data/sma.duckdb`. Coverage shows the data inventory table and a bar chart of recent ingest runs colored by status, plus the raw ingest log. Prices lets you pick a ticker and source, shows a candlestick OHLC chart with a date range picker, an adj_close overlay to see split/dividend adjustments, the last 30 rows in a table, and recent news headlines for that ticker. News provides filterable access to all articles with ticker, source, and date-range selectors. Backtest runs one of the three baseline strategies (buy_and_hold_spy, equal_weight, random_long) on the train or val window and displays a full metrics card, equity curve, and monthly returns bar chart. The test window is not available in the UI. Overfit runs both train and val windows and runs the five overfit checks, showing a pass/flag table and aggregate verdict.
