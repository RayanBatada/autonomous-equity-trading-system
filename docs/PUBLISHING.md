# Publishing the public copy

This repo is private. A public copy lives at
[RayanBatada/autonomous-equity-trading-system](https://github.com/RayanBatada/autonomous-equity-trading-system),
refreshed by hand, one commit per refresh, never with this repo's history.

## Refreshing it

```bash
git clone git@github.com:RayanBatada/autonomous-equity-trading-system.git /tmp/mirror
uv run python scripts/publish_public_mirror.py --mirror /tmp/mirror --ref main
cd /tmp/mirror && git status && git diff --stat     # read what changed
uv sync --all-extras && uv run pytest -n 4 -m "not serial"
git add <paths> && git commit && git push           # no force-push, ever
```

The script stops before syncing if `scripts/check_public_tree.py` finds anything below. The
public repo's CI runs the same check on every push.

## What stays out

- **Anything captured from the live account or the production database.** Real decide nights,
  fills, account snapshots, theses, broker order ids. Today that is
  `tests/fixtures/replay_2026_08_28.duckdb`, `tests/fixtures/scale_audit_2026_08_27*.json` and
  `tests/fixtures/sleeve_golden_prod_2026_09.json`. Their tests skip in the public copy; the
  replay and sleeve guarantees run there on `tests/fixtures/replay_synthetic.duckdb`, generated by
  `scripts/build_synthetic_replay_fixture.py` from a seeded random generator.
- **Database files in general.** Only the two allowlisted fixtures in `check_public_tree.py`
  may be `.duckdb`. Adding one means adding it there, on purpose.
- **Session notes and internal docs:** `CLAUDE.md`, `docs/superpowers/`.
- **Secrets:** `git archive` exports tracked files only, so `.env`, `data/`, `logs/` and
  `models_artifacts/` never come along; the check also searches every file for every value in
  this checkout's `.env`.

## What gets rewritten

- `/Users/youruser` to `/Users/youruser`, the Claude scratch-path form `-Users-youruser-`
  likewise, and the contact email to `your-email@example.com`.
- The README's badge points at the public repo's workflow, and its line about the public copy
  becomes a line saying this is that copy.
- `LICENSE` is the public repo's own and is kept.
